# STAYCUT · 스테이컷

소규모 숙소의 **촬영 → 채널별 납품 → 버전 승인 → 실제 게시 → 재활용**을 연결하는 서비스 기획안입니다.

초기에는 대표가 직접 제작하는 범위가 정해진 서비스로 시작하고, 반복 게시 수요와 원본이 충분한 숙소에 월 재편집을 제안합니다. 가격·원가·성과 목표는 검증 전 가설이며, 실제 고객 실적이나 완성된 운영 서비스가 아닙니다.

![스테이컷 서비스 컨셉](assets/overview.png)

## 고객 포털 개발 · 선택 시안 2번

[Vercel에서 개발 화면 열기](https://staycut-snap.vercel.app) · 체험 홈은 가상 데이터이며, 고객 로그인·RLS 조회·승인/수정 저장 코드를 별도 실제 고객 모드로 연결했습니다. 실제 DB 컬럼과 운영 서버 키·비공개 버킷 연결은 확인했습니다. 첫 계정·숙소·작업·파일 배정은 [관리자 안내](docs/supabase-setup.md)를 참고하세요. Vercel 프로젝트에 GitHub `devdevra/snap` 연결과 개발 브랜치의 자동 미리보기 배포를 확인했습니다.

[고객 포털 소스와 실행 안내](portal/README.md)에서 상단 탐색과 큰 숙소 사진을 사용한 반응형 프로토타입을 개발합니다. 홈 → 영상 검토·통합 수정 요청·정확한 버전 승인 → 게시용 콘텐츠·샘플 다운로드 → 게시 응답·재편집 문의를 연결했습니다.

```sh
npm run dev
npm test
npm run build
```

외부 npm 의존성 없이 Node.js 24.x에서 실행합니다. 단위 테스트, 임시 PostgreSQL의 권한 회귀 검사, 격리된 Auth/API/Storage 응답을 사용하는 Chromium 검증을 CI에서 실행합니다. 최신 결과와 실제 운영 환경 확인 범위는 [배포 기록](docs/deployment.md)에 구분해 기록합니다. 실제 결제·SNS 게시 연동은 없습니다.

## 개발 환경 · Vercel + Supabase

`/#manage`의 운영 관리 화면에서 숙소별 작업 현황을 확인하고 원본·별도 미리보기를 단계별로 전달합니다. 고객 관리에서는 확인된 기존 Auth 계정을 숙소에 추가하고 접근 기간 변경·권한 회수·지정 승인자 변경을 처리합니다. 고객사 소유자와 별도의 운영자 권한을 사용하며 승인 이력은 유지합니다. 새 고객 관리 기능에는 `202610160003_operator_members.sql` 추가 적용이 필요합니다. [운영자 안내](docs/operator-guide.md)에 설치·사용 순서와 실제 영상 확인 절차를 기록했습니다.

앱/API는 Vercel, 로그인·DB·비공개 파일은 관리형 Supabase로 진행합니다. [연결 상태와 배포 안내](docs/deployment.md), [Supabase 데이터 기반](supabase/README.md)을 참고하세요. 제공받은 프로젝트의 공개 키·Auth 접근, 서버 키로 앱 테이블/컬럼의 0행 조회와 비공개 버킷 확인이 통과했습니다. 사용자가 실제 로그인 성공을 확인했습니다. 실제 영상의 업로드 → 수정 → 승인 → 다운로드 전체 흐름은 아직 운영 환경에서 검증하지 않았습니다.

최신 관리자 고도화 [검증 CI](https://github.com/devdevra/snap/actions/runs/38828425290)에서 단위 테스트 128개·DB 판정 240개·브라우저 19개 흐름이 통과했습니다. 이 결과는 격리된 검증이며 실제 고객 영상의 전달 완료를 의미하지 않습니다.

## 인터랙티브 기획안 열기

저장소를 내려받은 뒤 `index.html`을 브라우저에서 엽니다. 외부 라이브러리, 패키지 설치, API 키가 필요하지 않은 단일 HTML입니다. GitHub의 파일 보기 화면에서는 HTML이 실행되지 않으므로 파일을 내려받아 열어야 합니다.

- 상단 탭에서 여섯 기획 화면을 전환합니다.
- 고객 여정의 단계를 선택하면 고객 행동·운영 업무·산출물·완료 조건이 표시됩니다.
- 보관함에서 상태 필터, 예시 버전 승인, 수정 요청을 시연할 수 있습니다. 실제 파일 전달이나 메시지 발송은 없으며 변경은 새로고침하면 초기화됩니다.
- 수익 계산기에서 작업시간·건수·가격·제작 가능 시간을 조정합니다. 표시된 잔액은 노동비와 직접비 차감 후 금액이며 순이익이 아닙니다.
- 브라우저의 인쇄 기능으로 현재 시뮬레이션을 포함한 전체 기획안을 PDF로 저장할 수 있습니다. 저장소의 공유용 PDF는 기본 가정으로 내보낸 문서입니다.

## 검증 범위

기획안 제작 시 Chromium으로 탭·고객 여정·필터·승인 조건·계산기 경계값·모바일 화면 등 50개 항목을 점검했습니다. 마지막 레이아웃 조정 후 모바일 6개 화면의 가로 넘침과 PDF 6쪽 출력도 확인했습니다. 이 기록은 프로토타입 검증이며 고객 인터뷰, 유료 판매, 시장 검증을 수행했다는 의미가 아닙니다.

첫 촬영 69만원, 월 재편집 19만원은 부가세 별도 가격 가설입니다. 기본 계산 예시인 첫 촬영 월 2건과 재편집 8곳은 매출 290만원, 총 작업시간 48시간, 노동·직접비 차감 후 잔액 110만원입니다. 영업비·고정비·세금과 실제 고객 확보는 별도로 검증해야 합니다.

자료 기준: 2026년 10월 15일 · 사용자가 제공한 Q2·Q3-1·Q3-2 내용을 바탕으로 작성.
