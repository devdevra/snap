## 1. 이번 기획의 권장 방향

초기에는 대표가 직접 제작하는 **범위가 정해진 촬영·재편집 서비스**로 시작한다. 고객이 구매하는 것은 보관함 자체보다 ‘지금 올릴 수 있는 사진·영상’과 ‘다음 홍보를 준비하는 수고의 감소’다. 보관함은 이 경험을 반복하기 위한 운영 도구다.

첫 촬영 패키지로 신규 고객을 확보하고, 실제 게시를 확인한 뒤 반복 수요가 있는 숙소에 재편집을 제안한다. 촬영 작가 중개, 대규모 SaaS, 예약 관리, SNS 운영대행은 초기 범위에서 제외한다. 자동화와 별도 제품 개발은 수작업으로 확인된 병목이 생긴 뒤 판단한다.

**핵심 성공 신호:** ‘파일을 받았다’에서 끝나지 않고, 승인한 콘텐츠를 고객이 실제 게시하고, 같은 원본으로 다음 콘텐츠를 유료 요청하는가.

### 근거의 구분

| 구분 | 현재 확인되는 내용 |

첨부 화면은 원자료에 명시된 **AI 생성 콘셉트·가상 숙소**다. 실제 제품 화면, 촬영 포트폴리오, 고객 실적으로 제시하지 않는다. 이 기획의 숫자 목표도 모두 검증을 위한 제안이며 달성 실적이 아니다.

## 2. 누구의 어떤 순간을 해결할 것인가

### 초기 고객

경기권에서 대표가 직접 운영하는 소규모 독립 숙소·펜션 가운데, 숙박 상품과 판매 채널은 이미 있지만 콘텐츠를 정기적으로 만드는 전담자가 없는 곳을 우선한다. ‘경기권’만으로 이동 원가가 통제되지는 않으므로 실제 활동 거점과 이동시간을 보고 기본 출장 범위를 정한다.

| 우선 상담할 조건 | 확인할 근거 |
| --- | --- |
| 가까운 시일에 소개할 이유가 있다 | 성수기 전 정비, 평일 상품, 새 객실 공개, 기존 사진 교체처럼 실제 일정이 있다. |
| 운영자가 결정하고 승인한다 | 견적·공간 사실관계·게시물 승인을 한 사람이 조율할 수 있다. |
| 게시할 채널과 담당자가 있다 | 현재 예약 상세 페이지 또는 SNS를 보여주고 누가 올리는지 설명할 수 있다. |
| 한 번의 촬영 범위가 작다 | 기본 객실 유형 1개와 공용 공간으로 첫 결과를 만들 수 있다. |
| 이용 가능한 촬영 시간과 권한이 있다 | 투숙객 없는 시간, 공간 접근, 인물·시설 촬영 가능 여부를 확인할 수 있다. |

객실 유형이 많거나 여러 승인자가 있는 대형 숙소, 전국 이동이 필요한 작업, 예약 실적 보장이나 매일 SNS 운영을 원하는 고객은 초기 표준 패키지와 적합성이 낮다. 별도 견적 또는 다른 서비스가 필요한 사례로 분류한다.

**첫 구매:** “예약 페이지와 SNS를 손보고 싶을 때, 여러 제작자와 파일을 조율하지 않고 실제 숙소 모습을 잘 전달하는 사진과 영상을 준비하고 싶다.”

**반복 구매:** “다음 홍보 주제가 생겼을 때, 지난 촬영 파일을 다시 찾고 설명하는 시간을 줄이면서 이번 채널에 맞는 콘텐츠를 받고 싶다.”

**정서적 가치:** 촬영 결과가 실제 숙소와 달라 보일까 걱정하지 않고, 어떤 파일을 어디에 써도 되는지 자신 있게 판단한다.

‘예약 증가’는 고객의 궁극적 바람이지만 가격·노출·계절·상품 경쟁력에 좌우된다. 초기 서비스가 직접 책임지고 측정할 결과는 납기, 게시 가능한 품질, 실제 게시, 파일 찾기 및 요청 시간, 유료 재사용이다.

## 3. 문제 가설과 경쟁 대안

### 먼저 검증할 네 가지

1. 촬영이 필요한 고객 중 상당수가 납품 뒤에도 게시용 파일 선별·비율 변경·수정 요청에 시간을 쓴다.
2. ‘사진 품질’ 외에 승인본과 사용범위를 함께 정리해주는 것에 추가 가치가 있다.
3. 같은 원본으로 만들 수 있는 다른 홍보 주제가 실제로 존재하며, 그 결과물에 반복 지불할 의사가 있다.
4. 이 작업을 촬영 12시간, 월 재편집 3시간 안팎의 총 작업시간으로 제공할 수 있다.

### 고객의 기존 선택과 스테이컷의 검증 과제

아래는 대안 유형에 대한 기획 비교다. 특정 업체의 상품을 조사한 결과가 아니며 기존 업체도 동일한 기능을 제공할 수 있다.

| 대안 | 고객에게 좋은 점 | 남을 수 있는 일 | 스테이컷이 증명할 가치 |
| --- | --- | --- | --- |
| 직접 휴대폰 촬영·편집 | 빠르고 현금 지출을 줄일 수 있다 | 운영자의 촬영·편집 시간, 품질 편차 | 운영 시간을 포함했을 때 맡길 이유가 있는가 |
| 일회성 사진·영상 제작 | 전문 제작 결과를 얻는다 | 다음 홍보용 재요청과 파일 정리 | 첫 제작부터 다음 사용을 준비하면 실제로 편한가 |
| 외주 편집자 | 촬영 없이 재편집을 맡긴다 | 원본 전달, 숙소 맥락과 권리 설명 | 공간과 이전 승인 맥락을 유지해 설명을 줄이는가 |
| 디자인·AI 편집 도구 | 수정 속도와 제작 자유도가 높다 | 원본 확보와 운영자의 판단·실행 | 도구 조작까지 맡기는 것이 비용 대비 유리한가 |
| 공유 폴더 | 저렴하고 익숙한 보관·전달 | 최신 승인본, 채널별 사용범위 확인 | 폴더에 운영 규칙을 더한 가치가 있는가 |
| SNS 운영대행 | 게시와 운영까지 위임한다 | 더 넓은 범위와 그에 따른 비용 | 직접 게시하려는 숙소에 좁은 범위가 맞는가 |

초기 차별점은 드론·AI·보관 기능의 독점성이 아니다. **숙소 이해 → 촬영 → 채널별 납품 → 특정 버전 승인 → 적법한 재편집**을 한 책임자가 반복 가능한 규칙으로 운영하는 데 있다. 이 방식의 우위는 아직 가설이다.

## 4. 서비스 구조: 세 번의 약속

### ① 촬영 전: 무엇을 누구에게 보여줄지 합의한다

숙소 운영자와 객실 유형, 주요 고객, 실제 제공 시설, 현재 판매 채널, 촬영 가능 시간, 게시 목표를 정한다. 견적서에 기본 범위·추가 항목·수정 횟수·초안 기한·고객 응답 기한·일정 변경 조건을 적는다.

촬영 목록은 ‘예쁜 장면’만 나열하지 않고 객실 선택에 필요한 정보와 연결한다. 예를 들어 침대와 동선, 욕실 구성, 공용 공간, 진입 경로, 실제 조망, 계절별 이용 가능 시설을 구분한다. 시설 제공 여부와 운영 조건은 숙소 운영자가 확인한다.

### ② 납품 시: 채널을 선택하면 올릴 파일이 보인다

보정 사진과 세로 영상을 용도별로 정리하고, 초안에는 미승인 상태를 표시한다. 고객은 한 번의 통합 피드백으로 수정 요청을 모아 전달한다. 승인 대상은 파일 전체가 아닌 **정확한 버전**이다.

납품 시 게시 대상 채널과 규격을 기록한다. 예약 사이트마다 규격이 다를 수 있으므로 ‘모든 플랫폼 호환’으로 약속하지 않고 상담 시 확정한 채널에 맞춘다. 고객의 게시를 돕는 파일 선택 안내는 제공하되 계정 운영과 실제 업로드 대행은 별도 범위다.

### ③ 납품 후: 다음번에 쓸 수 있는지 먼저 판단한다

고객 동의를 받아 게시 URL 또는 게시 여부를 확인하고 미게시 이유를 기록한다. 후속 콘텐츠는 현재 보유한 원본으로 표현할 수 있는 주제인지 검토한다. 실제로 촬영하지 않은 계절 풍경, 시설 또는 서비스를 있는 것처럼 만들지 않는다.

‘가을 여행’ 홍보도 원본에 가을 풍경이 없으면 단풍 장면을 만들어 넣는 대신 실내 휴식 등 확보된 장면과 사실에 맞는 주제로 제안한다. 부족한 장면은 신규 촬영 대상으로 표시한다.

## 5. 서비스 블루프린트

아래 응답·확인 일정은 운영을 위한 제안이며 실제 판매 전에 합의한다.

| 단계 | 고객 행동 | 고객에게 보이는 결과 | 내부 작업·담당 | 완료 조건·예외 |
| --- | --- | --- | --- | --- |
| 1. 적합성 상담 | 현재 페이지, 원하는 변화, 일정 공유 | 범위와 예상 비용 확인 | 대표가 촬영 범위·이동·승인자 확인 | 표준 범위 적합 또는 별도 견적 분류 |
| 2. 계약·준비 | 범위·사용허락·시간 합의, 시설 정보 제공 | 촬영 목록과 준비 안내 | 대표가 채널 규격·인물·음원·공간 권한 확인 | 필수 확인 누락 시 해당 장면 보류 |
| 3. 현장 촬영 | 공간 준비, 사실관계 확인 | 합의 범위 내 최대 3시간 촬영 | 대표가 사진·영상 장면을 함께 확보 | 날씨·투숙객·시설 사정 기록, 범위 추가는 견적 합의 |
| 4. 초안 제작 | 필요 정보에 응답 | 촬영 후 7영업일 이내 초안 목표 | 원본 정리, 선별, 보정, 편집, 권리 확인 | 날씨·필수자료 지연 등 예외를 계약에 명시 |
| 5. 통합 검토 | 한 번에 피드백 또는 승인 | 수정 요청·처리 상태 확인 | 대표가 합의 범위 내 통합 수정 1회 | 고객 확인 기한 제안: 3영업일. 미응답을 승인으로 처리하지 않음 |
| 6. 최종 납품 | 특정 버전 승인, 다운로드 | 승인본·채널·사용범위가 함께 표시 | 승인자·일시·버전 기록, 게시용 파일 묶음 제공 | 새 버전은 다시 승인, 구버전은 대체됨 표시 |
| 7. 게시 확인 | 직접 게시, 선택적으로 URL 공유 | 게시 체크와 간단한 사용 안내 | 납품 후 14일에 한 번 확인하는 안 | 미게시 사유 분류: 일정·품질·담당자·규격·기타 |
| 8. 재편집 제안 | 다음 홍보 주제 선택 | 보유 원본으로 가능한 2편의 주제 | 원본 다양성·권리·시설 현황 확인 | 제작 가능하면 월 재편집, 부족하면 단건/신규 촬영 제안 |
| 9. 종료·내보내기 | 계속 이용 또는 종료 선택 | 허용된 최종본·목록 내보내기 | 계약된 보관·삭제 일정 수행 | 영구 보관 약속 금지, 원본 제공 범위 별도 확인 |

**운영 예외의 원칙:** 범위 추가는 작업 전에 비용과 일정을 합의한다. 제작자의 오류 수정과 고객의 새 기획 요청을 구분한다. 고객 응답 지연 시 후속 일정을 재합의하되 승인 기록은 생략하지 않는다.

## 6. 권리·승인·버전은 서로 다른 정보다

원본 파일을 갖고 있다는 사실, 저작권을 소유한다는 사실, 광고에 쓸 수 있다는 사실, 특정 편집본을 승인했다는 사실은 같지 않다. 보관함은 이를 하나의 ‘승인 완료’ 배지로 합치지 않는다.

| 항목 | 계약·데이터에 남길 내용 | 고객이 확인할 질문 |
| --- | --- | --- |
| 저작권 귀속 | 촬영물·편집물의 권리 귀속과 양도 여부 | 누가 권리를 보유하는가 |
| 고객 이용허락 | 허용 매체·목적·기간·지역·유료 광고 여부·제3자 전달 조건 | 어디에, 언제까지 쓸 수 있는가 |
| 원본 제공 | RAW·소스 영상·프로젝트 파일·최종 납품본별 제공 여부 | 계약 종료 시 어떤 파일을 받을 수 있는가 |
| 제3자 권리 | 인물 동의, 음원, 폰트·편집 자산, 시설 등 필요한 이용 권한 | 이 소재를 해당 용도로 쓸 근거가 있는가 |
| 콘텐츠 승인 | 승인자·일시·대상 버전·확인 내용 | 어떤 화면·문구가 승인되었는가 |
| 보관·삭제 | 보관 기간, 계약 종료 후 유예기간, 내보내기·삭제 처리 | 언제까지 파일에 접근할 수 있는가 |

권리 조건이 미확인 또는 만료된 파일은 게시용 추천에서 제외한다. 유기적 SNS 게시가 허용된 음악도 유료 광고나 다른 플랫폼에서 허용되는지는 별도 확인한다. 최종 사용 가능 범위는 포함된 소재 중 가장 제한적인 조건을 반영한다.

**버전 규칙:** 원본 A에서 편집본 v1을 만들고 v1이 승인되었다면, 문구·음원·컷을 바꾼 v2는 승인 대기다. v1의 승인 이력은 남기며 v2 승인 후에는 최신본을 명확히 표시한다. 사용허락이 만료되면 승인 이력이 있어도 현재 사용 가능으로 표시하지 않는다.

고객 자료를 AI 학습에 재사용하지 않는다. 외부 AI 도구를 제작에 도입한다면 업로드 여부·보관·학습 정책을 검토하고 필요한 동의를 받는다. 고객 승인 없는 포트폴리오 게시를 하지 않는다. 드론은 선택 항목으로, 촬영 지역·대상·비행·안전·자격·사용사업·보험 등 적용 요건을 확인한 뒤 별도 견적한다. 불가하면 지상 촬영 또는 별도 일정을 제안한다.

## 7. MVP: 먼저 운영하고, 반복되는 부분부터 만든다

### 1단계: 서비스 MVP

기존의 안전한 파일 공유 공간, 표 형태의 관리대장, 버전을 명시한 승인 기록으로 시작할 수 있다. 고객별 접근 권한과 백업을 설정하고 계정 비밀번호를 공유받지 않는다. 특정 도구를 사용해야만 사업 가설을 검증할 수 있는 구조로 만들지 않는다.

한 숙소에 필요한 최소 운영 묶음은 촬영 브리프 1장, 납품 목록, 승인·사용범위 기록, 게시 확인 기록, 다음 주제 제안이다. 이 단계의 목적은 기능을 채우는 것이 아니라 반복 요청과 누락 지점을 발견하는 것이다.

### 2단계: 포털 MVP의 우선순위

| 우선순위 | 화면·기능 | 필요한 이유 |
| --- | --- | --- |
| P0 | 숙소별 작업 현황: 다음 행동·기한·담당자 | 무엇을 기다리는지 즉시 파악 |
| P0 | 모바일 검토: 버전 미리보기, 통합 피드백, 명시적 승인 | 승인 대기와 흩어진 수정 요청 감소 |
| P0 | 콘텐츠 보관함: 채널·주제·공간 필터, 최신 승인본, 사용범위, 다운로드 | 지금 쓸 파일을 빠르게 찾음 |
| P0 | 운영자 관리 화면: 촬영 목록·권리 상태·납품·시간 기록 | 누락과 원가 초과를 확인 |
| P1 | 재편집 요청: 주제·채널·기한·선택 원본 | 반복 설명을 줄임 |
| P1 | 게시 기록과 재사용 이력 | 실제 이용과 반복 수요 확인 |
| P1 | 계약 종료 시 내보내기·삭제 요청 상태 | 서비스 종료 절차를 일관되게 처리 |
| 보류 | 작가 매칭, 공개 마켓, 예약/결제 연동, SNS 자동 게시, 생성형 시설 합성 | 초기 핵심 가설 검증에 필요하지 않음 |

포털을 실제 고객에게 제공할 경우 고객별 접근 통제, 안전한 파일 링크, 기록 보존과 백업은 선택 기능이 아닌 기본 조건이다.

### 최소 데이터 모델

| 데이터 | 주요 필드 | 관계·주의점 |
| --- | --- | --- |
| 숙소 | 숙소 ID, 운영자, 승인자, 시설·객실 유형, 채널 | 여러 작업을 가진다 |
| 계약·주문 | 범위, 가격, 납기, 수정 횟수, 보관 조건 | 촬영/재편집 주문을 구분 |
| 촬영 | 일정, 장면 목록, 실제 촬영 정보, 총 작업시간 | 원본을 생성 |
| 원본 자산 | 자산 ID, 숙소, 공간·주제·촬영일·계절, 저장 위치 | 원본의 사실과 사용권 기록을 연결 |
| 편집본·버전 | 콘텐츠 ID, 버전 ID, 참조 원본, 음원·폰트 등 소재, 채널·규격 | 한 버전을 덮어쓰지 않음 |
| 권리·이용허락 | 권리자, 매체·목적·기간, 근거, 확인 상태 | 원본과 편집 소재에 각각 연결 |
| 검토·승인 | 버전 ID, 요청·피드백, 승인자·일시 | 승인 없는 버전을 자동 최종 처리하지 않음 |
| 게시·재사용 | 버전 ID, 게시 채널·일시·선택적 URL, 재편집 주문 | 다운로드와 실제 게시를 구분 |
| 작업시간·직접비 | 주문 ID, 기획·이동·촬영·편집·응대 시간, 비용 | 숨은 노동을 포함한 원가 판단 |

관계: **숙소 → 주문 → 원본 → 편집본의 버전 → 승인 → 게시**, 그리고 원본·소재 각각에 권리 조건을 연결한다. 같은 원본에서 여러 편집본이 만들어질 수 있다.

권장 상태 흐름: `준비 → 촬영 → 제작 → 검토 대기 → 수정 → 승인 → 납품 → 게시 확인 → 재사용 검토`. ‘권리 미확인/만료’는 이 제작 상태와 별도로 관리한다.

## 8. 상품·가격과 작업 범위

가격은 원자료의 시장검증 전 가설을 유지한다. 부가세 별도 공급가액이며 고객 제안에는 실제 결제 총액도 함께 표시한다.

| 상품 | 포함 범위 | 제외·별도 | 가격 가설 |
| --- | --- | --- | --- |
| 첫 촬영 패키지 | 숙소 1곳, 기본 객실 유형 1개+공용 공간, 현장 최대 3시간, 보정 사진 20장, 15~30초 세로 영상 2편, 통합 수정 1회, 촬영 후 7영업일 내 초안 목표 | 추가 객실, 장거리 이동, 모델, 드론, 범위 밖 수정 | 공급가 69만원 / 부가세 포함 75.9만원 |
| 월 재편집 관리 | 적법하게 확보한 기존 원본으로 월 세로 영상 2편, 통합 수정 1회, 주제 제안, 채널별 파일·승인 이력 정리 | 신규 현장 촬영, 광고 집행, SNS 계정 운영, 새로운 시설·계절 촬영 | 공급가 월 19만원 / 부가세 포함 월 20.9만원 |

재편집은 우선 3개월 동안 적합성을 검증한다. 원자료의 ‘3개월 검증’을 곧바로 의무 3개월 선결제나 최소 약정으로 해석하지 않는다. 이번 기획에서는 **월 단위 선택·청구로 시작하고 90일 뒤 갱신 의사를 평가하는 안**을 제안한다. 선결제, 중도 종료, 이월 여부는 판매 전에 명확히 합의한다.

### 판매 전에 정할 운영 상한

- 이동: 활동 거점, 기본 왕복 시간 또는 거리를 정하고 초과 이동 비용을 견적에 반영한다. ‘경기 전역 무료 출장’으로 넓히지 않는다.
- 수정: 통합 수정 1회가 포함하는 범위를 명시한다. 새 기획·새 원본·추가 길이·재촬영 요청은 추가 작업으로 구분한다.
- 규격: 기본 영상 길이·화면 비율·자막·음원·파일 형식과 채널별 추가 출력 여부를 확정한다.
- 고객 응답: 승인 담당자 1명, 통합 피드백 창구 1개를 기본으로 제안한다.
- 보관: 계약 중 보관과 종료 후 내보내기 유예기간을 계약에 명시한다. 실제 저장 원가 없이 무제한·영구 보관을 약속하지 않는다.
- 공급 오류: 제작자의 누락·파일 오류 처리는 고객의 추가 기획 수정과 별도 기준으로 정한다.

### 월 구독이 맞는 고객과 단건이 맞는 고객

| 월 재편집을 제안할 신호 | 단건·계절별 재편집이 나은 신호 |
| --- | --- |
| 서로 다른 주제로 재사용할 원본이 충분하다 | 비슷한 장면만 있어 다음 영상도 반복된다 |
| 다음 3개월의 홍보 주제가 실제로 있다 | 새 시설 공개 등 간헐적 사건만 있다 |
| 월 2편을 게시할 담당자와 계획이 있다 | 납품 후에도 게시할 시간이 없다 |
| 이전 콘텐츠를 실제로 사용했다 | 첫 결과물의 용도와 품질부터 해결해야 한다 |

적합하지 않은 숙소에는 억지로 월 구독을 붙이지 않는다. 단건 또는 분기·계절별 재편집은 수요 조사 후 원가에 맞춰 별도 가격을 검증한다. 기존 자료의 월 19만원을 근거 없이 그대로 단건 가격으로 정하지 않는다.

## 9. 단위경제성과 제작자의 시간

아래는 원자료의 가정을 계산한 값이다. 실제 장부상 이익이나 검증된 평균 원가가 아니다. 금액은 부가세 제외 기준이다.

| 항목 | 첫 촬영 1건 | 월 재편집 1개 숙소 |
| --- | ---: | ---: |
| 매출 가정 | 69만원 | 19만원 |
| 총 노동시간 가정 | 12시간 | 3시간 |
| 시간당 노동비 가정 | 3만원 | 3만원 |
| 노동비 | 36만원 | 9만원 |
| 교통·장비 사용·저장 등 직접비 | 10만원 | 2만원 |
| 합산 원가 | 46만원 | 11만원 |
| 영업·고정비·세금 등 차감 전 잔액 | 23만원 | 8만원 |
| 위 잔액 / 매출 | 약 33.3% | 약 42.1% |

첫 촬영과 재편집 3개월을 모두 구매했다면 공급가 합계는 126만원, 부가세 포함 총액은 138.6만원이다. 가정한 합산 원가는 79만원, 위 기준의 잔액은 47만원이다. 모든 고객이 이를 구매한다고 가정하거나 고객생애가치 실적으로 쓰지 않는다.

### 시간이 늘어날 때의 민감도

직접비와 시간당 노동비가 같다는 단순 가정이다.

| 상황 | 영업·고정비 등 차감 전 잔액 | 잔액 / 매출 | 판단 |
| --- | ---: | ---: | --- |
| 첫 촬영 총 12시간 | 23만원 | 33.3% | 원자료 기준 |
| 첫 촬영 총 13시간 | 20만원 | 29.0% | 1시간만 추가되어도 잔액률 30% 아래 |
| 첫 촬영 총 16시간 | 11만원 | 15.9% | 이동·수정·응대 초과 원인 점검 |
| 첫 촬영 총 20시간 | -1만원 | -1.4% | 영업·고정비 전에도 손실 |
| 월 재편집 총 3시간 | 8만원 | 42.1% | 원자료 기준 |
| 월 재편집 총 4시간 | 5만원 | 26.3% | 1시간만 추가되어도 잔액률 30% 아래 |
| 월 재편집 총 5시간 | 2만원 | 10.5% | 추가 응대·수정에 매우 취약 |
| 월 재편집 총 6시간 | -1만원 | -5.3% | 범위·가격·고객 적합성 조정 |

이번 기획에서는 **노동비·직접비 차감 후 잔액률 30% 이상**을 유지 목표로 제안한다. 현재 가격·직접비·시간당 노동비 가정에서 이를 유지하는 시간 상한은 첫 촬영 약 12.77시간, 월 재편집 약 3.77시간이다. 계산은 `(판매가 × 70% − 직접비) ÷ 시간당 노동비`이며, 실제 순이익률 목표와는 다르다. 운영 목표는 여전히 첫 촬영 12시간·월 재편집 3시간이다.

현재 가정에서 노동비와 직접비만 회수하는 시간 경계는 첫 촬영 약 19.7시간, 월 재편집 약 5.7시간이다. 실제 손익분기 시간은 영업·고정비 등을 포함하면 더 낮아진다. 이것을 허용 작업시간으로 운영하지 않는다.

### 초기 생산능력 예시

기본 시나리오는 **월 제작 가용시간 80시간, 첫 촬영 2건+재편집 8개 숙소**로 제안한다. 80시간은 월 총 근무시간에서 일반 영업·관리 시간을 미리 제외해 배정한 가정이며, 각 주문의 기획·이동·촬영·편집·수정·응대는 건별 노동시간에 포함한다.

| 항목 | 기본 시나리오 계산 |
| --- | ---: |
| 제작 노동시간 | 첫 촬영 2건 × 12시간 + 재편집 8곳 × 3시간 = 48시간 |
| 매출 | 2 × 69만원 + 8 × 19만원 = 290만원 |
| 직접비 | 2 × 10만원 + 8 × 2만원 = 36만원 |
| 노동비 | 48시간 × 3만원 = 144만원 |
| 영업·고정비 등 차감 전 잔액 | 290 − 36 − 144 = 110만원 |
| 잔액 / 매출 | 약 37.9% |
| 제작 가용시간 내 여유 | 80 − 48 = 32시간 |

32시간은 일정 변경·예상 밖 수정·장비 문제 등에 대비하는 여유시간이다. 이 계산은 매출이나 고객 확보를 보장하지 않으며, 영업·일반관리의 시간 비용과 고정비를 뺀 순이익도 아니다. 유료 고객 3~5곳의 실제 시간을 기록한 뒤 판매 가능한 슬롯을 정한다.

추가 시나리오로 첫 촬영 4건+재편집 10곳을 배정하면 78시간으로 여유가 2시간만 남는다. 실측 원가·납기와 운영 안정성을 확인하기 전에는 이를 기본 판매 목표로 삼지 않는다.

## 10. 8주 파일럿과 90일 갱신 평가

8주 안에는 첫 구매, 납품, 초기 재사용을 검증한다. 월 재편집의 지속성을 평가하려면 각 고객의 **재편집 시작일부터 최소 90일**을 관찰하고 이후 갱신을 확인해야 하므로 8주 파일럿만으로 구독 모델이 검증됐다고 결론 내리지 않는다.

| 기간 | 실행 | 남길 증거 |
| --- | --- | --- |
| 1~2주 | 적합 운영자 8명 인터뷰를 목표로 현재 파일·게시 흐름 확인 | 실제 최근 사례, 현재 지출, 반복 불편, 구매 거절 이유 |

고객 모집과 메시지 발송은 별도 실행 단계다. 이 문서는 실제 인터뷰나 고객 연락을 수행한 결과가 아니다.

### 측정 정의

아래 수치 기준은 모두 이번 기획의 **탐색 목표 제안**이며 달성 실적이나 통계적 검증 결과가 아니다. 숙소의 최초 게시와 납품 파일의 활용률을 서로 다른 지표로 관리한다.

| 지표 | 측정 방법·목표 제안 | 해석 시 주의 |
| --- | --- | --- |
| 첫 구매 유료 전환 | 표준 견적을 제안받은 적합 고객 5곳 중 3곳 실제 결제 목표 | 모집 채널·할인 여부와 실제 분모를 함께 기록 |
| 숙소 기준 최초 게시 | 최종 납품 후 14일 내 승인본을 1개 이상 게시한 숙소 수 / 해당 14일 관찰기간이 끝난 숙소 수. 초기 조건은 3곳 중 2곳 이상 | 확인 불가를 성공으로 계산하지 않고 별도 표시 |
| 파일 기준 게시비율 | 승인되고 사용 가능한 납품 고유파일 중 납품 후 14일 내 1회 이상 게시된 고유파일 수 / 14일 관찰이 끝난 승인·사용 가능 납품 고유파일 수. 목표 60% | 같은 파일을 여러 채널에 올려도 1개로 계산. 수정 구버전·기술적 복제본으로 분모를 늘리지 않고 최종 납품 목록 기준으로 집계 |
| 파일 검색·권리 확인 시간 | 같은 유형의 과제 5개를 기존 방식과 새 방식에서 수행해 검색부터 사용범위 확인까지 측정. 전후 중앙값 30% 단축 목표 | 과제의 난도·조건을 맞추고 순서에 따른 학습 효과를 기록. 회상 시간과 실제 측정을 섞지 않음 |
| 제작시간 | 상담 이후 주문별 기획·이동·촬영·편집·수정·응대 시간 합계. 첫 촬영 12시간·월 재편집 3시간 목표 | 대표의 무급 노동을 누락하지 않음 |
| 노동비·직접비 차감 후 잔액률 | `(매출 − 노동비 − 직접비) / 매출`. 30% 이상 목표 | 영업·고정비·세금 차감 전이며 순이익률이 아님 |
| 재편집 유료 선택 | 재편집 적합 고객 중 실제 주문·결제한 수. 적합 대상이 3곳이면 2곳 유료 전환을 탐색 목표로 제안 | 실제 적합 대상 수와 제안 수를 함께 기록. 적합 대상이 3곳 미만이면 ‘2/3 달성’으로 계산하지 않음 |
| 90일 갱신 | 재편집 시작 후 90일 관찰을 마친 고객 중 다음 유료 주문을 한 수 | 조사 중 고객과 무료 이용을 분모에서 분리 |
| 실제 재사용 | 이전 원본이 새로운 승인·게시 콘텐츠에 사용된 건수 | 같은 파일을 다시 내려받은 것과 구분 |

### 계속·수정·보류 판단 기준 제안

작은 표본은 통계적 시장 검증이 아니므로 아래 기준은 다음 행동을 정하는 운영 기준이다.

- **계속:** 숙소 기준 최초 게시가 3곳 중 2곳 이상이라는 초기 조건을 충족하면 다음 실험을 이어간다. 파일 게시비율 60%, 검색·권리 확인 시간 중앙값 30% 단축, 작업시간 12시간/3시간, 잔액률 30%, 적합 고객 3곳 중 2곳 유료 재편집은 함께 확인할 탐색 목표다. 일부 지표만 충족했다고 시장 검증 완료로 표현하지 않는다.
- **상품 수정:** 구매는 하지만 게시하지 못하면 파일 전달·채널 규격·게시 담당자를 먼저 개선한다. 제작 시간이 두 건 연속 가정을 초과하면 이동·수정·범위 또는 가격을 바꾼다.
- **구독 수정:** 첫 제작 만족은 높지만 반복 주제가 부족하면 단건·계절별 상품을 검증한다. 원본 부족을 편집 횟수로 메우지 않는다.
- **개발 보류:** 수작업 운영에서도 실제 게시나 유료 반복 수요가 약하면 포털 개발을 늘리지 않는다.

90일 고객이 3곳이라면 ‘갱신률 66.7%’만 크게 제시하지 않고 ‘관찰 완료 3곳 중 2곳 유료 갱신’처럼 실제 수와 관찰 조건을 함께 적는다.

## 11. 고객 인터뷰 질문

서비스 설명보다 최근 실제 행동을 먼저 묻는다. 응답을 실적으로 바꾸기 전에 인터뷰 동의와 기록 범위를 정한다.

1. 가장 최근 사진이나 영상을 새로 준비한 계기는 무엇이었나요? 실제 게시물을 함께 볼 수 있나요?
2. 누가 촬영·편집·게시했고, 외부 비용과 본인 시간이 각각 얼마나 들었나요?
3. 결과물을 받고 게시하기까지 어떤 일이 남았나요? 가장 오래 걸린 단계는 무엇이었나요?
4. 파일을 다시 찾거나 추가 편집을 요청한 최근 사례가 있나요? 어떤 대화와 파일을 주고받았나요?
5. 사용해도 되는 음악·사진·인물 권한이 불분명해서 쓰지 못한 적이 있나요?
6. 이전 사진이나 영상 중 실제로 여러 번 사용한 것은 무엇인가요? 사용하지 않은 이유는 무엇인가요?
7. 다음 3개월에 예정된 홍보 주제와 게시 담당자는 누구인가요?
8. 지금 이용하는 방법을 바꾸려면 반드시 좋아져야 하는 점과 포기할 수 없는 조건은 무엇인가요?
9. 지난번 실제로 결제한 범위·금액·선택 이유는 무엇인가요?
10. 이 범위와 총액이 적힌 제안을 받는다면 어떤 일정·조건에서 구매를 검토하나요? 검토하지 않는다면 무엇 때문인가요?

‘월 19만원이면 저렴하지 않나요?’처럼 답을 유도하지 않는다. 구두 호감과 실제 견적 수락·결제를 구분한다.

### Q2. 아이디어를 떠올린 배경

**[15년의 촬영·편집 경험에서 발견한 다음 과제]**

저는 스냅사진 촬영 분야에서 15년간 활동했고, 현재 프리랜서 촬영작가와 편집자로 일하고 있습니다. 공간의 구도와 빛을 판단하고 촬영부터 편집까지 연결하는 경험을 바탕으로, 소규모 숙소가 실제 공간의 매력을 소개하고 촬영 결과를 다음 홍보에도 활용할 수 있도록 돕는 ‘스테이컷’을 구상했습니다.

좋은 사진을 납품하는 것과 운영자가 그 사진을 지속적으로 홍보에 쓰는 것은 별개의 일입니다. 예약 페이지용 사진과 SNS 세로 영상, 계절별 소식을 각각 준비하려면 파일을 찾고, 채널에 맞게 바꾸고, 추가 편집을 요청해야 합니다. 자료가 여러 폴더와 대화방에 흩어져 있으면 최신 승인본과 사용 가능한 범위를 확인하기도 어렵습니다. 이러한 불편의 빈도와 지불 의사는 고객 인터뷰와 유료 파일럿으로 검증하겠습니다.

초기 고객은 경기권에서 대표가 직접 운영하는 소규모 독립 숙소·펜션으로 좁힙니다. 객실과 공용 공간을 한 번 촬영해 예약 페이지용 사진과 세로 영상을 납품하고, 이후에는 같은 원본에서 실제 표현 가능한 주제를 골라 재편집하는 방식입니다. 숙소를 실제보다 넓게 보이게 하거나 없는 시설을 합성하기보다, 공간의 매력을 정확히 보여주고 결과물이 실제 게시와 재사용으로 이어지도록 운영하겠습니다.

### Q3-1. 차별점과 해결하려는 문제

**[촬영에서 실제 게시와 재사용까지 연결하는 서비스]**

스테이컷은 소규모 숙소의 사진·영상 제작과 재편집을 정해진 범위로 제공하고, 납품본의 버전·승인·사용범위를 함께 정리하는 서비스입니다. 초기에는 대표가 직접 제작하며, 숙소 운영자가 지금 게시할 파일을 쉽게 선택하고 다음 홍보를 준비하는 시간을 줄이는 데 집중합니다.

촬영 전에는 주요 고객, 객실 유형, 소개할 시설, 게시 채널과 규격을 정합니다. 현장에서는 합의한 범위의 사진과 짧은 영상 소재를 함께 확보하고, 예약 페이지용 보정 사진과 세로 영상을 제작합니다. 운영자의 사실관계 확인과 통합 수정을 거친 뒤 특정 버전을 승인본으로 기록합니다. 드론은 비행·촬영과 관련된 적용 요건을 확인한 경우에만 별도 견적으로 제공하는 선택 항목입니다.

콘텐츠 보관함에는 공간·주제·촬영일·규격, 최신 승인본, 사용허락 범위를 함께 정리합니다. 이후 홍보에서는 기존 원본으로 가능한 편집과 신규 촬영이 필요한 내용을 구분합니다. 승인 기록이 있어도 음원 등 소재의 이용허락이 만료되면 사용 가능으로 표시하지 않으며, 촬영하지 않은 시설이나 계절 장면을 사실처럼 만들지 않습니다.

사진·영상 묶음이나 공유 폴더는 기존 서비스에서도 제공할 수 있습니다. 따라서 드론·AI·보관 기능 자체를 독점적 차별점으로 주장하지 않습니다. 숙소별 촬영 목록에서 채널별 납품, 버전 승인, 적법한 재편집까지 같은 규칙으로 운영하는 방식이 고객에게 더 편리한지 검증하겠습니다. 파일 찾기·추가 요청에 드는 시간, 납품 후 실제 게시, 유료 재편집과 갱신을 측정하겠습니다.

저작권 귀속, 이용허락의 매체·기간·목적, 원본 제공 여부, 보관과 종료 조건은 계약에서 구분합니다. 인물·음원 등 제3자 권리를 확인하고, 고객 자료를 AI 학습에 재사용하거나 승인 없이 게시하지 않습니다. 첨부된 콘셉트 화면은 AI 생성 가상 숙소이며 실제 제품 화면이나 고객 실적이 아닙니다.

### Q3-2. 수익 창출 계획

**[첫 촬영 패키지와 수요에 맞춘 재편집]**

첫 촬영 패키지와 월 재편집 관리로 수익을 검증하겠습니다. 아래 가격과 원가는 시장검증 전 가설이며, 가격은 부가세 별도 공급가액입니다. 실제 판매 제안에는 부가세 포함 총액을 함께 안내하겠습니다.

첫 촬영 패키지는 69만원으로 가정합니다. 숙소 1곳의 기본 객실 유형 1개와 공용 공간, 현장 최대 3시간, 보정 사진 20장과 15~30초 세로 영상 2편, 통합 수정 1회를 기본 범위로 합니다. 추가 객실·장거리 이동·모델·드론·범위 밖 수정은 별도 견적입니다. 촬영 후 7영업일 이내 초안 납품을 목표로 하며 날씨와 필수 자료 지연 등 예외는 계약에 명시합니다.

월 재편집 관리는 19만원으로 가정하고, 적법하게 확보한 기존 원본에서 세로 영상 2편과 통합 수정 1회를 제공합니다. 주제 제안과 채널별 파일·승인 이력 정리를 포함하며, 신규 현장 촬영·광고 집행·SNS 운영대행은 제외합니다. 원본과 게시 계획이 충분한 고객에게 제안하고, 3개월 동안 실제 사용과 갱신 의사를 확인하겠습니다. 반복 수요가 적은 고객에게는 단건 또는 계절별 이용 가능성을 별도로 검토하겠습니다.
