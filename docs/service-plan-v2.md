# 스테이컷 서비스 기획 v2 · 실행 설계 제안

작성: 2026년 10월 15일 · 기준 문서: [서비스 기획안](./service-plan.md)

**이번 고도화의 검토 기준 문서다.** v1의 핵심 사업 가설을 유지하고 고객 선별·상품 경계·게시 전환·총 노동 손익을 구체화했다. 실제 계약 조건을 확정한 문서는 아니다. 아래 신규 시간·수량·비용·판단 기준은 모두 검증을 위한 제안이다. 고객 조사, 계약, 촬영, 게시, 매출 또는 경쟁사 조사 결과를 새로 확인한 것은 없다. 기존의 첫 촬영 공급가 **69만원 / 부가세 포함 75.9만원**, 월 재편집 공급가 **19만원 / 부가세 포함 20.9만원** 가설을 유지한다.

## 30초 요약

**한 줄 제안:** 작은 숙소를 한 번 촬영해, 지금 게시할 사진·영상과 다음 홍보에 다시 쓸 수 있는 원본까지 함께 준비하는 제작 서비스.

첫 구매의 약속은 69만원 공급가의 정해진 촬영·제작 범위와 게시 준비다. 월 19만원 재편집은 첫 콘텐츠를 실제로 사용하고 다음 주제와 원본이 충분한 고객에게 월별로 제안한다. 핵심 지표는 가입자 수보다 **기한 내 실제 게시, 유료 원본 재사용, 대표의 전체 노동을 반영한 손익**이다.

- 고객 화면은 [제품 명세](product-spec.md)의 홈 → 검토 → 게시용 콘텐츠 흐름으로 좁힌다.
- [디자인 시안](../design/README.md)은 기존 그린·아이보리 브랜드에서 세 가지 정보 우선순위를 비교한다.
- 원본 `index.html`과 기존 PDF는 사업 설명용 v1이다. 이번 시안은 정적 이미지이며 실제 포털 구현이나 고객 검증을 완료한 상태가 아니다.

## 1. 고도화의 핵심 결정

스테이컷이 처음 증명할 일은 **한정된 숙소를 촬영해 실제 게시까지 연결하고, 필요한 고객에게 같은 원본으로 다음 유료 제작을 제공하면서 대표의 총 노동을 회수하는 것**이다. 보관함의 기능 수와 구독 신청 수를 먼저 늘리지 않는다.

| 결정 제안 | 원문에서 더 구체화하는 점 |

## 2. 첫 고객: ‘경기권 숙소’보다 좁은 한 집단

### 제안하는 첫 집단

**활동 거점에서 가까운 독채 또는 대표 객실 유형 1개인 소규모 독립 숙소 중, 예약 페이지와 SNS를 직접 운영하고 30일 안에 사진을 교체할 이유가 있는 운영자**를 우선한다. 운영자의 정확한 활동 거점은 아직 확인되지 않았으므로 시·군을 임의로 확정하지 않는다.

아래 다섯 가지를 모두 확인한 고객에게 표준 견적을 제안한다. ‘맞을 것 같다’와 확인된 조건을 구분해서 기록한다.

| 필수 조건 제안 | 상담에서 확인할 증거 | 맞지 않을 때 |
| --- | --- | --- |
| 기본 이동 범위 | 실제 촬영 시간대 기준 왕복 이동 90분 이내 | 이동·출장이 포함된 별도 견적. 무료 출장 지역을 광역 단위로 약속하지 않음 |
| 작은 현장 범위 | 실물 객실 1개, 공용 공간 최대 2구역, 합계 3시간 안의 촬영 목록 | 객실·구역을 줄이거나 추가 견적 |
| 구체적인 교체 일정 | 30일 내 예약 페이지 수정 또는 객실 소개 게시 예정일 | 일정이 생긴 뒤 재상담. 일정 없는 할인 판매를 피함 |
| 한 명의 승인자와 실제 게시 담당자 | 승인자 이름, 게시자, 채널 링크, 마지막 실제 게시 사례 | 담당자를 정한 뒤 견적 진행 |
| 공간·촬영 준비 가능 | 투숙객 없는 시간, 청소·침구·소품 준비, 시설 사실·촬영 권한 확인 | 불확실한 공간은 목록에서 제외하거나 일정 조정 |

SNS의 최근 운영 빈도도 별도 기록한다. 예를 들어 최근 30일 내 게시 2회 이상은 재편집 적합성을 살펴볼 신호로 제안하지만, 첫 촬영 구매의 절대 조건으로 삼지는 않는다. 예약 페이지 사진만 필요한 고객도 첫 촬영의 적합 고객이 될 수 있다.

### 첫 집단에서 알아낼 질문

첫 구매의 주된 이유를 **예약 페이지 사진 교체 / SNS 영상 확보 / 둘 다**로 나눠 기록한다. 사진 때문에 구매한 고객이 영상 2편을 받았다는 이유만으로 월 영상 구매 의사가 있다고 판단하지 않는다. 첫 고객 3곳은 이 구매 이유와 실제 사용 채널을 함께 비교한다.

표준 패키지와 맞지 않는 고객을 ‘관심 없는 리드’로만 기록하지 않는다. 장거리·다객실·승인자 부재·게시대행 필요·가격·일정 중 어떤 조건 때문인지 남긴다. 이 구분이 없으면 고객을 더 잘 선별해야 하는지 상품을 바꿔야 하는지 판단하기 어렵다.

영상 2편은 동일 영상을 자막만 바꿔 두 개로 세지 않는다. 예를 들어 확보한 실제 장면으로 ‘객실과 동선’과 ‘실내 휴식’처럼 다른 목적의 구성을 만든다. 두 번째 주제를 만들 원본이 없다면 계약 전에 상품 적합성을 재검토한다.

촬영 준비가 안 됐거나 날씨·투숙객·권한 문제로 필수 장면을 찍지 못했을 때, 완료한 범위와 남은 작업을 기록한다. 무조건 무료 재방문을 약속하지 않고 원인·추가 시간·비용·대체 일정을 사전에 합의한다.

### 승인과 보관을 끝까지 닫는 규칙

- 초안 요청 시 승인자에게 3영업일 내 통합 피드백을 요청한다. 미응답은 승인으로 간주하지 않는다. 응답이 없으면 확인 요청 1회 후 해당 작업을 보류하고 새 납기와 게시일을 재합의한다.
- 고객은 실제 시설·문구와 **정확한 버전**을 확인한다. 승인 버튼이나 승인 메시지에는 버전 ID·승인자·일시를 남긴다. 개별 파일이나 문구를 바꾼 새 버전은 다시 검토한다.
- 보관안은 원본·최종본 각각 기본 180일, 월 재편집 이용 중 필요한 자산은 계약 중 유지, 종료 후 내보내기 30일 유예로 제안한다. 기본 180일 종료일이 더 늦으면 늦은 날을 적용한다. 이 기간과 저장 원가는 파일럿에서 확인한다.
- 종료 안내에는 고객이 내려받을 최종본·목록·권리 조건과 삭제 예정일을 적는다. RAW 제공, 권리 양도, 영구 보관은 기본 약속에 포함하지 않는다. 원본이 삭제된 뒤 같은 자료의 재편집을 보장하지 않는다.

## 4. 월 19만원: 먼저 조건을 통과한 고객에게 제안

월 재편집은 ‘보관함을 이용하면 무조건 붙는 구독’이 아니라 **그달의 실제 제작 주문**으로 시작한다. 자동 결제나 최소 3개월 약정 없이 월별로 제작 주제와 기한을 합의하고 결제하는 방식을 제안한다.

### 네 가지 제안 조건

1. 첫 납품의 승인본을 고객이 실제로 게시한 기록이 있다. 게시하지 못했다면 먼저 원인을 해결한다.
2. 다음 2개월의 서로 다른 주제 4개를 고객이 선택할 수 있다. 가상의 계절 풍경·없는 시설·동일한 장면의 단순 반복으로 채우지 않는다.
3. 주제별 필요한 실제 장면과 현재 사용 가능한 원본·음원 권리를 확인했다. 자료 부족은 신규 촬영 제안으로 분리한다.
4. 월 2편의 게시일과 게시 담당자가 정해진다. 제작물을 받아도 올릴 계획이 없다면 월 상품을 권하지 않는다.

| --- | --- |
| 결과 | 기존 원본으로 15~30초 세로 영상 2편, 기본 9:16·1080×1920·MP4 |

| 청구 | 공급가 월 190,000원 / 실제 결제 총액 월 209,000원. 다음 달 제작 조건을 합의한 뒤 청구 |
| 그달 제작이 불가능할 때 | 확정 전 원본·주제가 부족하면 청구를 보류. 결제 후 제공자가 납품하지 못하면 고객과 환불·새 일정 중 처리 방법을 명시적으로 합의. 미사용 제작분이 조용히 소멸하는 방식은 피함 |

월 제작에 적합하지 않은 고객은 단건 또는 계절별 주문 후보로 남긴다. 단건 가격을 월 19만원과 자동으로 같게 정하지 않는다. 새 상품의 기획·대화·정리 시간이 얼마나 더 드는지 측정한 뒤 별도 견적한다.

## 5. 첫 구매 → 게시 → 다음 주문을 연결하는 운영

| 시점 | 고객과 정할 것 | 대표가 남길 증거 | 넘어가는 조건 |
| --- | --- | --- | --- |
| 계약 전 | 교체할 페이지, 먼저 소개할 객실, 첫 게시 예정일, 게시자 | 현재 페이지 링크·화면과 구매 주된 이유 | 30일 내 사용 상황과 담당자가 구체적임 |
| 촬영 브리프 | 사진 목록, 영상 주제 2개, 다음에 쓸 수 있는 주제 후보 | 실제 장면 목록과 사실·권리 체크 | 필수 장면을 현장에서 확보할 수 있음 |
| 촬영 당일 | 확보된 장면과 부족한 장면 확인 | 촬영된 원본에 공간·주제 태그 | 가상 장면 없이 첫 2편을 구성할 수 있음 |

3일 확인과 14일 확인은 각각 한 번의 짧은 메시지 또는 통화로 제안하며 작업시간에 포함한다. 고객 연락은 고객의 동의·선호 창구와 합의된 운영 범위에서 실제 실행한다. 이 문서 작성 과정에서 고객에게 연락한 것은 아니다.

미게시 사유는 **게시일 미도래 / 담당자 시간 부족 / 파일·규격 문제 / 내용·품질 불만 / 권리·시설 정보 미확인 / 확인 불가 / 기타**로 구분한다. ‘귀찮아서 안 올림’처럼 추측해서 분류하지 않는다. 제작자 오류는 고치고, 담당자 부재는 다음 판매의 적합성 조건을 바꾸는 근거로 삼는다.

예약 페이지 사진 교체와 SNS 영상 게시는 작업 목적이 다르다. ‘20장 중 몇 장이 올라갔는가’만 보지 않고 **고객이 합의한 예약 페이지 교체가 끝났는가**, **영상 2편 중 몇 편을 게시했는가**도 나눠 본다. 예약 수·조회 수가 변하더라도 스테이컷만의 인과 효과로 주장하지 않는다.

## 6. 대표의 숨은 시간을 포함한 손익

### 시간을 세 갈래로 기록한다

1. **주문 제작 노동:** 계약 이후 브리프·이동·촬영·백업·편집·수정·승인·납품·게시 확인. 첫 촬영 12시간, 월 재편집 3시간 가설을 유지한다.
2. **고객 획득 노동:** 해당 고객군의 모집·상담·견적·계약에 쓴 시간. 계약하지 않은 상담도 포함하고 획득한 유료 고객 수로 나눈다.
3. **일반 영업·관리 노동:** 미래 고객을 위한 일반 영업, 정산·세금 자료 정리, 장비·파일 관리 등 특정 주문이나 획득 활동에 붙이지 못한 시간. 앞의 두 항목과 중복 기록하지 않는다.

| 첫 촬영 12시간의 시간 예산 제안 | 시간 |
| --- | ---: |
| 계약 후 브리프·장면·권리 확인 | 0.75h |
| 왕복 이동 | 1.50h |
| 현장 촬영·설치·현장 이동 | 3.00h |
| 파일 정리·백업 | 0.50h |
| 사진 선별·보정 | 2.50h |
| 영상 2편 편집 | 2.00h |
| 통합 피드백·수정 | 0.75h |
| 출력·검수·최종 정리 | 0.50h |
| 게시 준비·후속 확인 | 0.50h |
| 합계 | **12.00h** |

이는 달성된 생산성이 아니다. 특히 영상 2편 편집 2시간과 사진 20장 선별·보정 2.5시간이 가능한지 첫 3건에서 확인한다. 시간을 맞추려고 검수·백업·권리 확인을 생략하지 않는다.

월 재편집 3시간의 제안 예산은 주제 확인 0.25h, 원본 선택 0.50h, 편집 1.25h, 출력·검수 0.25h, 통합 수정 0.50h, 승인·납품·게시 기록 0.25h다. 주제별 새로 긴 상담을 해야 하면 이 가정은 즉시 재검토한다.

### CAC는 현금과 노동을 따로 본다

예를 들어 **후보 20곳 → 상담 8곳 → 표준 견적 5곳 → 결제 3곳**, 해당 모집·견적 활동의 현금 지출 18만원·노동 12시간이라는 가정을 놓을 수 있다. 이는 모집 실적이나 전환율 예측이 아닌 계산 예시다.

- 현금 CAC: 18만원 ÷ 신규 결제 3곳 = **6만원/곳**.
- 획득 노동: 12시간 ÷ 신규 결제 3곳 = **4시간/곳**.
- 노동 포함 CAC: 6만원 + 4시간 × 시간당 3만원 = **18만원/곳**.

현금 CAC와 노동 포함 CAC를 동시에 전액 비용으로 더하지 않는다. 노동 포함 CAC 안에 현금 CAC가 이미 들어 있다. 광고 없이 소개로 왔어도 상담·견적 시간이 0은 아니다. 결제 고객이 0곳이면 CAC를 0으로 쓰지 않고 ‘지출 18만원·12시간, 획득 0곳, 1곳당 CAC 산정 불가’로 기록한다.

### 주문별 보수적 예시: 현금이 남아도 노동 보상은 다르다

아래는 부가세를 제외한 제안 계산이다. 기존 직접비 첫 촬영 10만원·재편집 2만원을 각각 **현금 7만원+비현금 장비 사용분 3만원**, **현금 1만원+비현금 장비 사용분 1만원**으로 나눠 예시를 만들었다. 실제 현금 지출과 감가·장비 원가 구분을 확인한 결과가 아니다. 직접비에 넣은 비용을 고정비에 다시 넣지 않는다.

| 항목 | 첫 촬영 1건 | 월 재편집 1곳 |
| --- | ---: | ---: |
| 공급가 매출 | 69만원 | 19만원 |
| 주문 직접 현금 지출 | -7만원 | -1만원 |
| 신규 고객 현금 CAC | -6만원 | 0만원 |
| **일반 고정비·대표 인출 전 현금 잔액** | **56만원** | **18만원** |
| 비현금 직접비 | -3만원 | -1만원 |
| 주문 노동비: 12h / 3h × 3만원 | -36만원 | -9만원 |
| 신규 획득 노동비: 4h × 3만원 | -12만원 | 0만원 |
| **일반 영업·관리와 고정비 배분 전 노동 손익** | **5만원** | **8만원** |

재편집 열의 CAC 0원은 같은 고객의 첫 획득비를 첫 촬영에 이미 모두 반영한 이 예시에서만 성립한다. 새 고객에게 편집 상품만 직접 판매하거나 추가 영업이 들면 해당 비용·시간을 따로 반영한다. 매달의 주제 확인·청구·승인 대응은 재편집 3시간에 들어 있다.

첫 촬영의 원문 잔액 23만원은 이 예시에서 현금 CAC 6만원과 획득 노동비 12만원을 더 반영하면 **5만원**으로 줄어든다. 이 금액에도 일반 영업·관리, 고정비, 세금은 아직 빠져 있다. 초기 첫 구매를 미래 구독 매출로 무조건 보전한다고 가정하지 않는다.

### 월간 보수적 예시: 원문 2건+8곳의 다시 계산

기존 월 구성인 첫 촬영 2건+재편집 8곳, 공급가 매출 290만원을 유지한다. 현금 CAC 6만원/신규 고객, 월 일반 고정 현금비 20만원, 일반 영업·관리 24시간을 **추가 가정**한다. 고정비는 주문 직접비와 중복되지 않는 소프트웨어·보험·통신·관리비 등의 예산이며 실제 장부 금액이 아니다.

| 항목 | 제안 계산 |
| --- | ---: |
| 공급가 매출 | 2×69 + 8×19 = **290만원** |
| 주문 직접 현금 지출 | 2×7 + 8×1 = -22만원 |
| 신규 고객 현금 CAC | 2×6 = -12만원 |
| 일반 고정 현금비 | -20만원 |
| **대표 생활비 인출·세금·장비 재투자 전 현금 잔액** | **236만원** |
| 비현금 직접비 | 2×3 + 8×1 = -14만원 |
| 주문 제작 노동 | 48h × 3만원 = -144만원 |
| 신규 획득 노동 | 8h × 3만원 = -24만원 |
| 일반 영업·관리 노동 | 24h × 3만원 = -72만원 |
| **총 80시간 노동 보상을 반영한 예시 손익** | **-18만원** |

원문에서 생산 슬롯으로 배정한 80시간 가운데 실제 제작 48시간을 쓰고 남는 32시간은 예약 여유다. 위 표의 총 노동 80시간은 **제작 48+획득 8+일반 관리 24**의 합이며 그 여유 32시간을 중복 노동으로 계산하지 않았다. 여유 슬롯을 실제로 작업·영업에 쓰면 해당 시간을 추가한다.

236만원은 사업자의 순이익이나 대표 월급이 아니다. 개인사업자의 자기 노동은 당장 현금으로 나가지 않아 현금이 남을 수 있으나, 비현금 직접비 14만원을 빼고 노동 80시간으로 나누면 세전 노동 보상 가능액은 시간당 약 **2.78만원**이다. 제안한 시간당 3만원을 전부 회수하려면 같은 주문 구성·비용에서 월 공급가 매출이 최소 308만원이어야 한다. 이 역시 비용이 변하지 않는 단순 산식이며 가격 인상 결과를 예측한 것은 아니다.

고객에게 받는 부가세를 매출에 더해 잔액을 부풀리지 않는다. 세금 납부·공제, 대표 인출, 장비 재투자, 회수 지연은 별도 현금계획에 기록한다. 첫 촬영 2건과 재편집 8곳이 동시에 확보됐다는 실적이나 8주 내 도달 가능한 상태로 제시하지 않는다.

### 손익에 따른 다음 행동

- 주문 제작 잔액률 30%는 원문의 운영 목표로 계속 측정하되, **CAC·일반 관리까지 반영한 노동 손익이 음수라면 흑자 사업이라고 표현하지 않는다.**
- 첫 3건이 모두 끝나면 실제 현금 CAC·획득 시간·일반 시간·직접비로 월 예시를 다시 계산한다. 3곳의 고객이 모두 재편집을 산다는 가정은 쓰지 않는다.
- 초과 시간을 만드는 한 요소부터 줄인다. 이동이 길면 반경, 통합 수정이 깨지면 창구, 사진과 영상 동시 제작이 무리면 패키지 구성을 먼저 조정한다. 새 고객에게 바뀐 견적을 제시해 결제를 확인한다.
- 현재 가격에서 범위 축소로도 총 노동 보상을 회수하지 못하면 가격을 다시 검증한다. 추가 구독 수로 손실을 가릴 계획을 세우지 않는다.

## 7. 8주 실험: 만들기보다 관찰 가능한 순서를 잡는다

**목표는 유료 첫 촬영 3곳까지, 적합 고객의 초기 유료 재편집을 관찰하는 것이다.** 표본이 작아 시장 수요나 장기 구독을 검증했다고 주장하지 않는다. 파일럿 운영 예산 상한으로 총 현금 지출 100만원·대표 노동 120시간을 제안하며, 실제 지출·고객 모집은 별도 실행 계획에서 확정한다. 고객에게 받은 돈과 현금 지출 상한을 상쇄해서 무제한 집행하지 않는다.

| 기간 | 진행할 일 | 최소 기록·판단 |
| --- | --- | --- |
| 1주 | 거점·범위 확정, 후보 조건 적용, 인터뷰 시작, 견적·촬영·승인·기록표 준비 | 조건별 적합/부적합과 이유. 인터뷰를 구매 의향 조사로 대체하지 않음 |
| 2주 | 총 인터뷰 8곳을 탐색 목표로 현재 게시 흐름 확인. 적합 고객 5곳에 표준 총액·범위 견적 | 실제 상담 수·견적 수·할인·계약 조건·결제 수. 견적 마감 7일이라는 관찰 창을 제안 |
| 3~4주 | 결제 고객 최대 3곳 촬영·제작. 세 번째 촬영을 무리하게 넣지 않고 원가 기록 | 주문별 활동 타이머, 직접비, 원본 적합성, 통합 수정 횟수, 최초 초안 납기 |
| 4~5주 | 가능한 고객부터 승인·납품. 초기 게시 안내·기술 확인 | 버전 승인·최종 납품일. 14일 관찰 종료일을 고객별 자동 계산 |
| 5~6주 | 관찰이 끝난 고객의 실제 게시 확인. 네 조건을 통과한 고객에게 다음 달 유료 재편집 제안 | 제안 적합 수·실제 제안 수·결제 수. 미게시 사유와 거절 사유 |
| 6~8주 | 결제한 재편집 제작·승인·납품. 첫 상품과 월 상품 각각 원가 재계산 | 새 주문·실제 원본 재사용·게시 관찰 가능 여부. 8주 말에 미성숙 지표 표시 |
| 이후 | 각 재편집 시작일로부터 90일 관찰, 그다음 실제 유료 주문 확인 | 관찰 완료 수·갱신 수·종료 사유. 8주 결과에 섞지 않음 |

예를 들어 7주차에 재편집을 최종 납품했다면 납품 후 14일의 게시 관찰은 9주차에 끝날 수 있다. 8주 보고서에는 ‘관찰 중’이라고 쓰고 종료 전 결과를 성공·실패로 확정하지 않는다. 고객의 승인을 빨리 받기 위해 무응답을 승인으로 처리하지 않는다.

### 기록표 한 줄의 구조

`숙소ID / 모집 경로 / 구매 이유 / 적합 조건 / 견적일·총액·할인 / 결제일 / 촬영·납품일 / 버전 / 게시 관찰 종료일 / 게시 확인 방법·일시 / 미게시 사유 / 재편집 적합 여부·이유 / 제안일·결제일 / 신규 주문 원본ID / 주문·획득·일반 시간 / 현금·비현금 비용 / 상태`

연락처·계약·비공개 게시 화면은 필요한 사람만 접근한다. 공개 시안과 검증 보고서에는 가상 숙소와 집계 수치를 사용하고 실제 고객 신원을 넣지 않는다.

## 8. 숫자 보고와 중단 기준

### 게시 증거 수준을 먼저 정한다

**판정 제안:** 버전·채널·게시일이 있는 운영자의 게시 응답을 `운영자 자기신고`로 보존한다. 고객 동의하에 받은 URL·화면을 제작자가 확인했다면 `URL/화면 확인`으로 별도 기록한다. URL이 없다는 이유로 응답을 버리지 않으며 자동 플랫폼 검증으로 표현하지 않는다.

아래 최초 게시 지표와 3곳 중 2곳이라는 운영 기준은 **자기신고를 포함한 운영자 응답 기준**이다. 보고할 때 `운영자 응답 기준 2/3, 이 중 URL/화면 확인 1곳`처럼 증거 수준을 함께 쓴다. 이는 보고 형식의 예시이지 고객 실적이 아니다. 확인 불가인 고객과 아직 관찰 중인 고객은 성공으로 계산하지 않는다. 향후 URL/화면 확인만을 지표로 사용할 때에는 실험 시작 전에 정의를 변경해 서로 다른 분모·기준의 결과를 섞지 않는다.

### 분모를 먼저 정한다

| 지표 | 집계 정의 | 따로 표시할 항목 |
| --- | --- | --- |
| 표준 견적 구매 | 관찰 창이 끝난 표준 견적 고객 중 실제 결제한 수 / 해당 견적 수 | 회신 대기, 맞춤 견적, 할인 구매. 인터뷰 수를 구매 분모로 쓰지 않음 |
| 숙소 최초 게시 | 납품 후 14일이 지난 숙소 중 승인·사용 가능 콘텐츠 1개 이상 게시했다고 응답한 수(자기신고 포함) / 해당 숙소 수 | 14일 미경과는 분모 밖. 14일이 지났지만 확인 불가면 분모에 포함하고 미확인으로 표시, 성공에는 넣지 않음 |
| 예약 페이지 교체 | 예약 페이지 교체가 주 구매 목적이며 관찰이 끝난 숙소 중 합의한 페이지 교체를 확인한 수 | SNS 게시만으로 사진 교체 목적을 달성한 것으로 계산하지 않음 |
| 영상 활용 | 관찰이 끝난 최종 승인 영상 중 실제 게시된 고유 영상 수 / 해당 고유 영상 수 | 재출력·썸네일·구버전 제외. 사진과 별도로 집계 |
| 초기 재편집 결제 | 네 조건에 맞는 고객 중 실제 유료 결제 수. 적합 수·제안 수·결제 수를 모두 기재 | 주제 부족·원본 부족 등 비적합. 첫 촬영 고객 전체를 적합 분모로 간주하지 않음 |
| 실제 재사용 | 이전 촬영 원본이 새 승인본에 쓰이고 실제 게시까지 확인된 새 콘텐츠 수 | 결제했지만 제작 중, 납품했지만 관찰 중, 단순 재다운로드 |
| 90일 갱신 | 재편집 시작 후 90일 관찰이 끝난 고객 중 다음 유료 주문을 한 수 / 해당 관찰 완료 수 | 시작 안 함, 90일 미경과, 무료 제공, 납부 대기 |

원문의 전체 파일 게시비율 60%와 검색·권리 확인 시간 30% 단축은 보조 탐색 지표로 남긴다. 사진·영상 수량 구성과 과제 난도에 따라 수치가 바뀌므로 이 둘만으로 서비스 유효성을 판정하지 않는다.

예시 보고 표현은 ‘관찰 완료 3곳 중 2곳 게시, 1곳 확인 불가; 별도 1곳 관찰 중’이다. 보고서가 이를 ‘게시율 66.7%’ 하나로 줄이지 않도록 한다. 이 문장은 보고 형식 예시이며 실제 고객 결과가 아니다.

### 사전에 정할 판단 기준 제안

| 조건 | 다음 행동 |
| --- | --- |
| 적합 견적 5곳의 7일 관찰 창이 모두 끝났는데 결제 0곳 | 유료 촬영 상품 모집을 잠시 멈추고 거절 이유를 확인. 고객 집단·첫 사용 상황·범위·가격 중 한 가설을 바꾼 새 제안을 시험. 무료 제작으로 전환 성과를 대체하지 않음 |
| 5곳 견적 중 1~2곳 결제 | 그 고객까지는 운영·원가를 측정. 원문의 3/5 탐색 목표 미달로 표시하고 추가 고객 확대 전 메시지·대상·범위를 한 번 수정 |

| 관찰 완료 3곳 중 게시 0~1곳 | 신규 모집 확대와 포털 개발을 보류하고 막힌 단계 확인. 제작·규격 오류는 정정하고 일정·담당자 문제는 선별 조건 수정 |
| 첫 촬영 2건 연속 12시간 초과 또는 월 재편집 2건 연속 3시간 초과 | 새 주문 전 원인 한 가지를 정해 범위·반경·가격 수정. 낮은 시급으로 가정을 맞추지 않음 |
| CAC·일반 관리 포함 노동 손익이 실제 기록에서 음수이고, 다음 수정안으로도 회수가 어려움 | 동일 조건 판매 확대를 중단하고 상품 재설계. 첫 구매 손실을 아직 없는 갱신 매출로 메우지 않음 |

| 재편집 적합 고객이 3곳 미만 | ‘표본 부족/적합성 부족’을 명시. 2/3 달성처럼 원래 목표 분모를 유지하지 않음. 특히 원본 부족이면 촬영 목록부터 수정 |

첫 3곳 중 1곳이 미관찰이면 2곳의 결과를 3곳의 결과로 늘리지 않는다. 한 번의 작은 실험에서 미달했다고 전체 시장이 없다고 결론 내리지도 않는다. **이번 조건에서 다음 고객을 같은 방식으로 받아도 되는가**를 판단하는 기준이다.

## 9. 화면 시안에 반영할 제품 요구

디자인은 고객이 오늘 해야 할 행동과 게시 가능한 파일을 찾는 데 집중한다. 실제 구현·고객·매출 화면으로 오해되지 않게 **콘셉트 시안 / 가상 숙소·샘플 데이터**임을 표시한다.

1. **작업 홈:** 다음 행동 1개, 담당자·기한, 현재 촬영/제작/검토 상태, 합의 범위·결제 총액은 작업 정보 링크에서 확인. 숫자 KPI나 예약 증가 차트를 첫 화면에 두지 않는다.
2. **모바일 검토:** 큰 미리보기, 정확한 버전, 사용 채널·시설 문구, 통합 피드백과 명시적 승인. ‘승인’과 ‘현재 사용 가능한 권리’는 별도 표시한다.
3. **게시 파일:** ‘먼저 올릴 사진 5장’, ‘SNS 영상 2편’ 묶음, 용도·규격·최신 승인본·사용범위. 다운로드와 실제 게시 상태를 따로 둔다.
4. **다음 콘텐츠:** 현재 원본으로 가능한 주제와 새 촬영이 필요한 주제를 구분한다. 적합 조건을 확인한 뒤 월 209,000원의 다음 제작을 제안한다. 기본 동작은 요청 확인이며 무의식적인 자동 구독 가입을 만들지 않는다.
5. **대표 운영 화면:** 고객별 원가·총 시간·현금 CAC·관찰 종료일·미확인 이유를 본다. 고객에게는 필요한 일정·행동·파일을 보여주고 내부 손익 표를 섞지 않는다.

시안에 보이는 진척·가격·파일 개수는 제안 조건 또는 샘플이다. ‘실제 고객 000곳’, 고객 후기, 매출 그래프, 시장 점유율은 새로 만들어 넣지 않는다.

## 10. 파일럿 시작 전 확정할 여섯 가지

1. 대표의 활동 거점과 이동 상한, 사진·영상에 필요한 실제 제작 가능 시간.
2. 유료 견적서의 포함·제외·결제·일정 변경·취소 조건과 사용허락.
3. 최종 파일 형식·원본 제공 여부·보관·내보내기·삭제 일정.
4. 승인자·게시 담당자·첫 교체 페이지·게시 예정일.
5. 주문별 노동, 획득 노동, 일반 영업·관리와 현금·비현금 비용의 기록 방식.
6. 8주 지출·시간 상한과 고객별 관찰 종료일, 수정·보류 판단 담당자.

이 항목들이 정해지면 작은 유료 파일럿을 진행할 수 있다. 포털 개발의 증거는 파일 저장량이 아니라 반복해서 발생하는 승인 대기·파일 선택·게시 장애와 이를 줄였을 때의 실제 노동 절감이다.
