# STAYCUT 동일 홈 화면 디자인 비교 브리프

기준일: 2026-10-15 (Asia/Seoul)

이번 세 이미지는 **동일 기능·동일 상태·동일 콘텐츠의 홈 화면**을 비교한다. 기존 next-action / content-library / version-review 이미지는 서로 다른 기능 화면이며 선택형 대안으로 부르지 않는다.

## 공통 정보와 행동 — 모든 이미지에 동일

- 제품: STAYCUT / 온유스테이 / `가상 숙소 · 디자인 시안`.
- 최상위 탐색: `홈 · 검토함 · 콘텐츠`이고 홈이 선택됨.
- 제목: `다음 게시를 준비해 볼까요?`
- 설명: `온유스테이의 새 영상을 확인해 주세요.`
- 현재 작업: `10월 숙소 소개 영상` / `검토 대기 · v2` / `세로 영상 2편 · Instagram`.
- 사용 범위: `사용 범위 확인 완료 · 자체 SNS`.
- 핵심 버튼 하나: `영상 검토하기`. 홈에서 직접 승인하거나 다운로드하지 않는다.
- 동일한 4단계: `촬영 완료 → 편집 완료 → 고객 검토 → 게시 준비`; 현재는 고객 검토.
- 아래 보조 영역: `승인본만 모았어요`, 보조 링크 `게시용 파일 보기`.
- 동일한 승인본 세 개: `마음이 머무는 테라스`(00:28), `아침이 다른 온유스테이`(00:24), `저녁 노을이 머무는 시간`(00:25).
- 세 승인본의 공통 상태: `승인 완료 · 자체 SNS 사용 가능`, `게시 여부 미확인`.
- 날짜가 들어간다면 2026-10-15. 표시하지 않아도 되지만 다른 날짜로 바꾸지 않는다.

## 비교할 축

정보 계층·레이아웃·타이포그래피·사진 배치·브랜드 색의 비중만 바꾼다. 기능·프로젝트·파일 수·상태·버튼 문구는 바꾸지 않는다. 어느 쪽이 현재 작업과 주행동을 더 빨리 찾게 하는지 비교한다.

1. 작업 중심: 왼쪽 사이드바, 단정한 제품 UI, 간결한 검토 영역, ivory와 forest green.
2. 에디토리얼: 상단 탐색, 큰 제목과 사진의 비대칭 편집, 넓은 여백, 동일한 검토 행동.
3. 스튜디오: 짙은 녹색 상단과 따뜻한 ivory 작업 영역, 별도 진행 레일, 동일한 검토 행동.

각 이미지에는 단일 1440 × 1024 데스크톱 홈 뷰포트만 표시한다. 브라우저·기기 목업·여러 화면 합성은 사용하지 않는다. 기존 기획 `assets/overview.png`와 기존 고객 홈 `design/next-action.png`를 실제 이미지 참조로 첨부한다.

이미지 생성의 글자·아이콘 오차가 있으면 정확한 제품 요구는 이 공통 브리프와 `docs/product-spec.md`를 따른다. 정적 화면의 시각 비교이며 상호작용이나 접근성 검증 결과가 아니다.
