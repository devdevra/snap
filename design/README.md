# STAYCUT 디자인 비교와 서비스 흐름

작성일: 2026-10-15 · 브랜드: forest green / ivory / sage

**디자인 대안은 같은 화면끼리 비교한다.** 기존의 홈·보관함·검토 이미지는 서로 다른 기능 화면이다. 이 세 기능을 대체안처럼 선택하도록 안내했던 분류를 바로잡았다. 새 홈 대안 세 개는 같은 정보·상태·버튼을 유지하고 배치와 시각 표현만 바꾼 비교 자료다. 화면 속 온유스테이와 숙소 이미지는 모두 가상 예시이며 실제 제품이나 고객 검증 결과가 아니다.

## 같은 홈 화면의 디자인 대안

| 방향 | 이미지 | 달라지는 디자인 |
| --- | --- | --- |
| 작업 중심 | [home-task-focused.png](home-task-focused.png) | 왼쪽 탐색, 간결한 작업 블록, 수평 진행 표시 |
| 에디토리얼 | [home-editorial.png](home-editorial.png) | 상단 탐색, 큰 제목, 사진과 문구의 비대칭 배치 |
| 스튜디오 | [home-studio.png](home-studio.png) | 짙은 녹색 상단, 따뜻한 작업 영역, 세로 진행 레일 |

세 이미지 모두 **같은 고객의 같은 검토 대기 상태**다. `10월 숙소 소개 영상 / 검토 대기 · v2 / 세로 영상 2편 · Instagram`, 주행동 `영상 검토하기`, 같은 4단계, 같은 승인본 세 개를 보여준다. 기능이나 프로젝트·파일 수·상태를 바꿔 디자인 차이로 설명하지 않는다. 세부 공통 문구는 [비교 브리프](home-variants-brief.md), 실제 이미지 정보는 [대안 이미지 기록](home-variants-manifest.json)을 따른다.

비교할 것은 현재 작업과 주행동을 찾는 속도, 정보의 읽기 순서, 사진과 여백, 브랜드 인상이다. 기능이 더 많아 보이는 화면을 좋은 디자인으로 판단하지 않는다.

## 기존 세 이미지는 서비스 흐름의 기능 화면

| 화면 | 이미지 | 사용자가 하는 일 |
| --- | --- | --- |
| 홈 | [next-action.png](next-action.png) | 현재 검토할 작업과 다음 행동 확인 |
| 콘텐츠 보관함 | [content-library.png](content-library.png) | 채널에 맞는 최신 승인본 다운로드 |
| 버전 검토 | [version-review.png](version-review.png) | 특정 버전 확인, 통합 수정 요청 또는 승인 |

이 세 화면은 경쟁하는 대안이 아니라 한 서비스에 함께 필요한 작업 흐름이다. 홈에서 검토를 시작하고 정확한 버전을 승인한 뒤, 수납과 사용 조건을 충족한 최종 파일을 콘텐츠 보관함에서 받는다. 기존 이미지 기록은 [manifest.json](manifest.json)에 보존했다.

## 공통 디자인·제품 기준

- 데스크톱 기준 프레임은 1440 × 1024다. 실제 생성 이미지의 픽셀 크기는 기록 파일에 별도로 남긴다.
- 기존 기획 `assets/overview.png`와 기존 고객 홈 `next-action.png`를 새 세 대안의 실제 이미지 참조로 첨부했다.
- 숲색 `#254e3a`, 아이보리 `#f4f3ed`, 세이지 `#e9ede2`, 라임 `#d5e89a`과 목재·린넨·자연광 사진을 기본 언어로 삼는다.
- 홈·검토함·콘텐츠를 기본 탐색으로 사용한다. 홈의 핵심 행동은 검토 화면으로 이동하는 것이며 홈에서 곧바로 승인·다운로드하지 않는다.
- 승인 여부, 사용 가능한 범위, 실제 게시 여부를 나눈다. 다운로드가 게시 완료를 뜻하지 않는다.
- 가격·기한·권리·수납 판정은 [고도화 기획](../docs/service-plan-v2.md)과 [제품 명세](../docs/product-spec.md)를 따른다.

홈 대안을 선택한 뒤 같은 디자인 언어를 콘텐츠 보관함과 검토 화면에 적용한다. 기존 `index.html`과 PDF는 사업 설명용 v1이며 이번 고객 화면의 구현물이 아니다.

모든 이미지는 정적 디자인 자료다. 생성 이미지의 작은 문구·아이콘 오차는 구현 시 명세에 맞춘다. 실제 상호작용·모바일·접근성·서버 권한을 검증한 결과로 표현하지 않는다.
